# KnowledgeEngine

KnowledgeEngine è un motore di conoscenza locale progettato per costruire una base di conoscenza strutturata a partire da documenti aziendali.

L'obiettivo del progetto è sviluppare una piattaforma in grado di:

- acquisire documenti eterogenei;
- estrarre conoscenza strutturata;
- costruire automaticamente una wiki aziendale;
- creare un grafo di relazioni tra entità;
- permettere interrogazioni in linguaggio naturale tramite LLM completamente in locale.

Il progetto è sviluppato con un'architettura modulare, estendibile e indipendente dai singoli modelli AI utilizzati.
